# vega-chip-sdk — Capabilities

## Per-capability inventory

| Capability | Why policy-or-prompt-level cannot provide it | Where enforced in code | Test demonstrating it | Honest limit |
|---|---|---|---|---|
| **Write-once key store (1–4 Ed25519 pubkeys)** | A prompt cannot prevent key replacement; code in same process can overwrite `self.keys` | `GEU.program_keys` raises `Denied("keys_blown")` if `self.keys` already set; keys appended to NV chain | `test_keys_are_written_once` | Python convention; same-process code can mutate `geu.keys` directly |
| **Single-use nonce burn before gate opens** | Policy cannot enforce burn-before-gate ordering; model could be tricked into skipping | `GEU._check` burns nonce (appends to NV, read-back) **before** appending GRANTED decision; `GEU.request` returns Grant only after both appends succeed | `test_the_burn_comes_before_the_gate_and_a_refused_request_burns_nothing` | Power cut between burn and grant append leaves nonce burned (approval spent) — by design |
| **Closed-by-default output gate, one transaction per grant** | Prompt cannot enforce gate token; code can call port.write directly | `_Port.write` requires `gate is _GATE` object; `GEU.transact` verifies grant matches `self._open[port]`, not used, not expired; then clears grant | `test_the_gate_is_closed_by_default_and_opens_for_one_transaction_on_the_granted_port` | Same-process code can construct `_GATE` if it imports the module; not a hardware gate |
| **Hard stop engageable by anyone, liftable only by human commitment** | Policy cannot make stop irrevocable without human key | `GEU.hard_stop()` sets `hard_stopped=True`, clears grants, appends `hard_stop`; `GEU.restore` requires valid commitment for `restore_after_hard_stop` via `_check` | `test_a_hard_stop_by_anyone_and_a_restore_only_by_the_human` | Stop state survives restart (read from chain); human key must be available to lift |
| **DMA side-door table: human-signed config, enforced on egress** | Prompt cannot bind DMA initiators to ports | `GEU.program_dma` requires commitment for `change_gate_config` over exact canonical table; `GEU.egress` checks `port in self.dma.get(initiator, set())` | `test_dma_reaches_a_port_only_through_the_table_the_human_signed` | Table stored in chain; survives restart; no runtime mutation without human commitment |
| **Bypass detection (raw_port_write) with optional hard-stop trip** | Policy cannot detect code reaching port without gate | `GEU.raw_port_write` always appends `DENIED side_door`, then calls `port.write(object(), payload)` which fails gate check; if `trip_on_side_door`, calls `hard_stop()` | `test_a_write_that_skips_the_unit_is_refused_recorded_and_trips_the_stop` | Only catches bypass via this method; direct `port.log.append` not prevented (Python convention) |
| **Monotonic clock with rollback refusal at start** | Prompt cannot enforce clock monotonicity | `MonotonicClock.advance` only forward; `GEU.__init__` reads all records, finds max `t`, faults if `clock.read() < last_t` | `test_a_clock_that_reads_earlier_than_the_record_makes_the_unit_refuse` | Only checked at init; continuous rollback not detected |
| **Power-cut-safe NV: dual region, read-back, torn-write discard, one-record repair** | Policy cannot enforce physical write ordering or recovery | `NVStore.append` writes both regions, flushes, fsyncs, reads back both, compares to intended record; `_recover` discards torn tails, repairs 1-record gap, faults otherwise | `test_a_power_cut_mid_write_is_discarded_and_leaves_the_unit_failed_until_restart`, `test_a_cut_after_one_region_finished_is_repaired_from_it` | Software model only; real hardware needs battery-backed NV, atomic sector writes |
| **PRE locked workflow: code/input/output hash verification, budget metering, hash-on-chain-before-release** | Prompt cannot verify code hash at runtime; no budget enforcement | `Run.step` verifies `step_id` order, `code_sha256`, `inputs_sha256`; `Meter.charge` traps on exceed; result hash appended via `GEU._append` before return | `test_a_locked_workflow_runs_in_order_and_each_result_hash_is_on_the_chain_first`, `test_every_deviation_traps_before_anything_runs`, `test_budgets_crashes_wrong_outputs_and_non_bytes_all_trap_and_release_nothing` | Code hash is hash of bytes handed to unit (not measured boot); budget driven by harness `charge()` |
| **Quarantine for unlocked workflows: gate refuses Quarantined results** | Prompt cannot wrap/unwrap return types at gate | `Run.step` returns `Quarantined(bytes)` if `self.quarantined`; `GEU.transact` raises `Denied("bad_payload")` on non-bytes | `test_an_unlocked_workflow_runs_only_in_quarantine_and_the_gate_refuses_its_output` | Caller could unwrap `Quarantined.value` and pass raw bytes (Python convention) |
| **Taint for accelerator results without locked output hash** | Prompt cannot distinguish accelerator vs local compute | `Run.step` with `accelerator=True` returns `Tainted` if no locked `output_sha256`; `GEU.transact` refuses `Tainted` | `test_an_accelerators_output_is_tainted_unless_a_locked_hash_vouches_for_it` | Only works if caller honestly sets `accelerator=True`; no hardware attestation |
| **Conformance: GEU and software jacket decide identically on all vectors** | Policy cannot prove two implementations match | `conformance.run_conformance` runs same signed bytes through jacket `ExitGate` and GEU; any mismatch recorded | `test_the_hardware_model_and_the_software_jacket_decide_alike_on_every_vector` | Vectors cover known attack classes; not exhaustive of all possible inputs |
| **Mutation resistance: 46/48 mutations killed** | Policy cannot guarantee test suite catches rule removal | `tests/mutations_chip.py` applies 48 rule-removal mutations; runs test suite; survivors reported | `mutations_chip.py` output: 2 survivors (`nv read-back`, `hard stop blocks the gate`) | 2 known survivors documented; not a formal proof |

## DKG + lattice integration (this repo's part in the family predictive loop)

**This repo does not directly import or consume the DKG/lattice SDKs.** Its role in the predictive loop is **downstream**:

1. **Records → chain** — Every GEU decision (`GRANTED`, `DENIED`, `burn`, `hard_stop`, `restore`, `dma`, `pre_lock`, `pre_revoke`, `pre_result`, `pre_refused`) is appended to the hash-chained NV store, which sits on top of `vega-custody-sdk`'s ledger. These records are the **ground truth** the DKG/lattice consumes.

2. **Lessons → librarian** — The chain records (especially refusals, traps, conformance mismatches) are the raw material `vega-librarian-sdk` (layer 5) distills into lessons.

3. **Knowledge graph → dkg-lattice** — Lessons become facts in `vega-dkg-lattice-sdk` (layer 7) with origin (this SDK, this commit, this test run) and licence.

4. **Lattice → reasoning/galaxy** — `vega-reasoning-sdk` (layer 11) and `vega-galaxy-sdk` (layer 14) forecast from the lattice: e.g., "this GEU configuration has seen X replay attempts in Y deployments; the lattice predicts Z risk if lease cap is raised."

5. **Harness pre-registers predicted paths** — `vega-harness-sdk` (layer 6) uses lattice foresight to pre-register predicted workflow steps in the PRE unit (via `lock_pre` commitments), so the hardware model runs anticipated paths with full verification.

6. **Metacog gates completion** — `vega-metacog-sdk` (layer 12) checks evidence rungs: did the PRE workflow complete? did conformance pass? are there unresolved refusals?

7. **Feed/galaxy show human** — `vega-governance-feed-sdk` (layer 13) and `vega-galaxy-sdk` present the full picture to the human, who decides the next commitment.

**This SDK's wiring:** It **exports** the chain (`GEU.chain()`, `NVStore.records`) and **consumes** `vega-custody-sdk` (ledger backend) and `vega-governance-jacket-sdk` (commitment format, verifier). It does not import `dkg-lattice`, `reasoning`, `galaxy`, `harness`, `librarian`, or `metacog` — those are up-layer consumers.

## A category of its own: honest differentiation

| Differentiation claim | What THIS design does | Why it follows from architecture |
|---|---|---|
| **Authority held outside the model** | The human's Ed25519 private key never touches the machine running the GEU/PRE. Commitments are signed offline and presented as opaque bytes. | The GEU only verifies signatures under programmed public keys; it has no signing capability. `GEU._verifies` is pure verification. |
| **Deterministic conductor (no model in the loop)** | The GEU's check sequence is fixed code: 12 steps in order, first failure denies. The PRE unit's step verification is fixed: order, code hash, input hash, budget, output hash. | No LLM, no heuristic, no policy evaluation in the critical path. `GEU._check` and `Run.step` are pure deterministic functions. |
| **Pre-registered predicted paths** | `PREUnit.lock` requires a human commitment for the exact workflow + step list (code hashes, input hashes, budgets). The harness can pre-register these from lattice foresight. | Locking is a gate operation (`GEU._check("lock_pre", ...)`) — authority spent once per workflow. No silent replacement (`already_locked`). |
| **Single-use human commitments** | Every `request`, `restore`, `program_dma`, `lock_pre`, `revoke_authority` consumes a unique nonce burned in NV. Replay denied. | `GEU.burned` set tracks spent nonce hashes; `_check` rejects if `nh in self.burned`. Burn happens before gate opens. |
| **Chain-of-custody by default** | Every decision, refusal, lock, revoke, result, hard stop, DMA change is appended to the dual-region hash chain with read-back. | `GEU._append` and `NVStore.append` enforce dual-write + read-back + hash chaining. Chain survives power cuts and restarts. |
| **Lattice-informed foresight (via up-layer wiring)** | The chain this SDK produces feeds the DKG → lattice → reasoning → harness → PRE lock pipeline. The human sees forecasts before committing. | This SDK does not run the lattice; it produces the immutable record the lattice reasons over. The loop closes when the human's next commitment reflects the forecast. |

> **Note on "competitors cannot" claims:** The only such claim made here is that **authority held outside the model cannot be replicated by prompt-level policy** — because a prompt is evaluated by the model itself, and the model (or a hijacker steering it) can ignore or rewrite the prompt. This argument is from WHITEPAPER.md Section 1 and follows from the architecture: the GEU's gate token (`_GATE`) is a Python object the model cannot forge without importing the module, and the human's private key is never on the model's side.
